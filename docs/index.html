Быстрый старт

git clone https://github.com/bitplugg/kitsune.git
cd kitsune && bash install.sh

kitsune                      # REPL (или python3 main.py)
kitsune -c 'use doctor; run' # одиночная команда
kitsune --resource etc/example_chain.rc

kitsune > use portscan
kitsune (network/portscan) > set target 10.0.0.1
kitsune (network/portscan) > run

kitsune (network/portscan) > interact 0
kitsune (shell) > id

Почему kitsune

Общая база сессии

SQLite (~/.kitsune/session.db): hosts, ports, subdomains, loot, sessions. Данные «текут» между модулями — pipeline в стиле unix.

Live-сессии, как в msf

sessions и interact <id>: подключённый reverse-shell иcпользуется интерактивно прямо из REPL; автопроб (id/whoami/uname) — в loot.

Chain-DSL (resource)

resource file.rc с переменными ${target} — автоматизация пентеста без единой строчки кода.

REST API + team-sync

api/serve: JSON /api/hosts /api/loot /api/report. team/sync: push/serve обмен loot между операторами.

TUI-дашборд

dashboard: curses-панели — статистика, группы модулей, hosts, последний loot.

Отчёты md/HTML

report audit.md | audit.html — выбираешь формат; html с тёмной темой, готов к браузеру/PDF.

Случайные ASCII-баннеры 🎲

5 артов × 5 цветов × 20 tips — каждый вход в лису видится по-новому (как в msfconsole).

Чистый stdlib

Ядро — только Python-библиотека: socket/sqlite3/curses. scapy — опционально для wireless, NVD API — для cve_search.
